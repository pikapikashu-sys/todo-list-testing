# TC-007. Редактирование текста задачи

**Требование:** REQ-04
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
Приложение открыто, в списке есть задача «Купить хлеб».

## Шаги
1. Нажать на кнопку «Редактировать» (или дважды кликнуть по тексту задачи).
2. Очистить поле и ввести новый текст «Купить молоко».
3. Сохранить изменения (нажать «Сохранить» или клавишу Enter).

## Ожидаемый результат
Текст задачи успешно изменен на «Купить молоко» и отображается в списке.
