# TC-014. Адаптивность 320px

**Требование:** REQ-10
**Тип:** UI [ю-ай]
**Приоритет:** Средний

## Предусловия
Приложение открыто в браузере на ПК.

## Шаги
1. Открыть инструменты разработчика (DevTools, F12).
2. Включить режим эмуляции мобильного устройства.
3. Установить ширину экрана 320px.

## Ожидаемый результат
Интерфейс приложения корректно адаптируется под ширину экрана 320px. Отсутствует горизонтальная прокрутка. Все элементы (текст, кнопки, чекбоксы) видны, не наезжают друг на друга и доступны для нажатия.
