# TC-009. Фильтрация «Активные»

**Требование:** REQ-06
**Тип:** Функциональный
**Приоритет:** Средний

## Предусловия
Приложение открыто. В списке задач присутствуют как активные, так и выполненные задачи.

## Шаги
1. Нажать на фильтр (или вкладку) «Активные».

## Ожидаемый результат
В списке отображаются только невыполненные (активные) задачи. Выполненные задачи скрыты из отображения.
