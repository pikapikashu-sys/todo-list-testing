# TC-011. Очистка выполненных задач

**Требование:** REQ-07
**Тип:** Функциональный
**Приоритет:** Средний

## Предусловия
Приложение открыто. В списке есть несколько выполненных и несколько активных задач.

## Шаги
1. Нажать на кнопку «Очистить выполненные» (Clear completed).

## Ожидаемый результат
Все выполненные задачи удаляются из списка. Активные задачи остаются без изменений.
