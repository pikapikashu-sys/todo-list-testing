# TC-010. Фильтрация «Выполненные»

**Требование:** REQ-06
**Тип:** Функциональный
**Приоритет:** Средний

## Предусловия
Приложение открыто. В списке присутствуют как активные, так и выполненные задачи.

## Шаги
1. Нажать на фильтр (или вкладку) «Выполненные».

## Ожидаемый результат
В списке отображаются только выполненные задачи. Активные задачи скрыты из отображения.
