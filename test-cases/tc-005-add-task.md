# TC-005. Добавление задачи длиной 201 символ

**Требование:** REQ-02
**Тип:** Граничный
**Приоритет:** Средний

## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Ввести текст, состоящий из 201 символа.
2. Нажать «Добавить».

## Ожидаемый результат
Задача не добавляется в список. Появляется сообщение о превышении лимита символов (или ввод блокируется на 200-м символе).
