# TC-013. Счётчик активных задач

**Требование:** REQ-09
**Тип:** UI [ю-ай]
**Приоритет:** Низкий

## Предусловия
Приложение открыто. В списке есть 2 активные задачи.

## Шаги
1. Добавить новую активную задачу (например, «Позвонить маме»).
2. Отметить одну из активных задач как выполненную.

## Ожидаемый результат
При добавлении новой задачи счетчик активных задач увеличивается на 1 (становится 3). При отметке задачи выполненной — уменьшается на 1 (становится 2). Показания счетчика всегда соответствуют реальному количеству активных задач.
