# TC-006. Отметка задачи как выполненной

**Требование:** REQ-03
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
Приложение открыто, в списке есть активная задача (например, «Купить хлеб»).

## Шаги
1. Нажать на чекбокс (или кнопку статуса) напротив задачи «Купить хлеб».

## Ожидаемый результат
Задача «Купить хлеб» меняет статус на выполненную (например, текст зачеркивается, меняется цвет, или задача перемещается в раздел «Выполненные»).
