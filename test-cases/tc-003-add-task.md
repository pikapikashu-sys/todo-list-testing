# TC-003. Добавление задачи из пробелов

**Требование:** REQ-01
**Тип:** Негативный
**Приоритет:** Высокий

## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Ввести в поле ввода только пробелы (например, «   »).
2. Нажать «Добавить».

## Ожидаемый результат
Задача не добавляется в список. Появляется сообщение об ошибке валидации (пробелы не считаются валидным текстом).
