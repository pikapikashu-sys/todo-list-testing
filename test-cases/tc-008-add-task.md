# TC-008. Удаление задачи

**Требование:** REQ-05
**Тип:** Позитивный
**Приоритет:** Высокий

## Предусловия
Приложение открыто, в списке есть задача «Купить хлеб».

## Шаги
1. Нажать на кнопку «Удалить» (иконка корзины или крестик) напротив задачи «Купить хлеб».
2. (Если есть) Подтвердить удаление в диалоговом окне.

## Ожидаемый результат
Задача «Купить хлеб» исчезает из списка задач.
