# TC-015. Отмена редактирования по Escape

**Требование:** REQ-04
**Тип:** Негативный
**Приоритет:** Низкий

## Предусловия
Приложение открыто. В списке есть задача с текстом «Купить хлеб».

## Шаги
1. Перевести задачу в режим редактирования (двойной клик или кнопка «Редактировать»).
2. Изменить текст на «Купить молоко».
3. Нажать клавишу `Escape` на клавиатуре.

## Ожидаемый результат
Режим редактирования закрывается. Изменения отменяются. Текст задачи остается прежним — «Купить хлеб».
