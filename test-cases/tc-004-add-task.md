# TC-004. Добавление задачи длиной 200 символов

**Требование:** REQ-02
**Тип:** Граничный
**Приоритет:** Средний

## Предусловия
Приложение открыто, список задач пуст.

## Шаги
1. Ввести текст, состоящий ровно из 200 символов.
2. Нажать «Добавить».

## Ожидаемый результат
Задача успешно добавляется в список. Текст отображается в полном объеме (все 200 символов).
